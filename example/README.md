# Legacy MAPLE example

helloworld.py is the smallest legacy messaging example in this repository.
Run it from the repository root after installing the package:

~~~bash
python -m pip install -e .
python example/helloworld.py
~~~

For current examples and the MAPLE 2.0.0 capability boundary, see the [root
README](../README.md) and the [examples index](../examples/README.md).
