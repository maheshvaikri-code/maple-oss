## Release rationale

MAPLE 2.0.0 promotes the accumulated autonomous-runtime, interoperability,
security, reliability, retrieval, and task-management surface to the next
major package version. This release also reconciles the checked-in CI contract:
all strict Flake8 findings are fixed in source, all MAPLE modules carry the
existing author notice, and no lint or license policy was weakened or changed.

The release marker is a major-version promotion. The version change itself
does not claim that hosted coordination, managed stores, sandboxed execution,
or external registry services are included; those remain explicit follow-up
contracts in the parity plan.

## Deferred parity work

The following are planned, not silently represented as complete in 2.0.0:

- hosted identity, tenancy, policy, and managed control-plane services;
- distributed scheduling, leases, federation, and exactly-once side effects;
- managed state/vector stores and provider-owned retrieval services;
- sandboxed code execution, browser/computer control, and isolation policy;
- hosted observability/evals, language breadth, and production hosting.

See [the parity follow-up plan](../plans/maple-agent-framework-parity-followups.md).

Security and public-claim follow-ups that are not release blockers are tracked
in the [2.0.0 remediation plan](../plans/maple-2.0.0-follow-up-remediation.md).
