# Skill: Fundraising

**Scope.** Investor updates, pitch narrative, data room, diligence prep —
investor truth at cadence. Pairs with `roles/investor-relations.md`.

## Principles
- Updates ship on a fixed cadence even when the update is hard —
  especially then. Silence reads worse than the worst true number.
- Every metric comes from `docs/metrics/` artifacts with its fidelity
  label — never from memory, never reconstructed for the occasion.
- A KPI is defined once — formula, source, window — and holds that
  definition across every update. A KPI that shifts meaning between
  updates is a lie with extra steps.
- Lowlights get the same font size as highlights; the charter penalizes
  fiction, not bad news.
- One caught embellishment costs the round. Diligence answers are
  verbatim-honest or the whole data room becomes suspect.

## Defaults
- Update template: highlights, lowlights, metrics with fidelity labels,
  asks — the same sections every cycle, so omissions are visible.
- Projections labeled as projections, assumptions adjacent in the same
  block — never footnoted where nobody reads.
- Data room versioned and dated per document; the index regenerated to
  match actual contents before every share.
- Diligence answers quote source artifacts; where the true answer is
  "we don't track that yet", that is the answer.
- Everything is a draft: updates, decks, and diligence responses queue
  for the human to send (.Doctrine.md §5); commitments are the human's.

## Do
- Reconcile the pitch narrative against the last update the same investor
  received; divergence is fixed at the source, not spun.
- Pre-answer the hard question: if a metric fell, the update says so
  first and explains before anyone has to ask.
- Keep a KPI definitions page in the data room and cite it from every
  update; a changed definition is announced and restated historically.
- Prune the data room on schedule; a stale document found in diligence is
  a credibility hit the current documents pay for.

## Don't
- Don't quote a number without its artifact and fidelity label.
- Don't redefine a KPI mid-story to make the line go up.
- Don't bury a lowlight in paragraph nine.
- Don't present projections in results' clothing.
- Don't answer diligence from memory or approximation — pull the artifact
  or say it doesn't exist.

## Review checklist
- [ ] Update on cadence; hard news included, prominent, and plain
- [ ] Every metric traces to docs/metrics/ with fidelity label intact
- [ ] KPI formulas, sources, windows unchanged — or the change declared
- [ ] Projections labeled, assumptions adjacent in the same block
- [ ] Data room index matches contents; documents versioned and dated
- [ ] Draft queued for the human; nothing sent, promised, or signed

## Common failure modes
The skipped update in the bad month that tells investors everything;
metrics reconstructed from memory drifting a few points flattering; KPI
definitions quietly migrating until the chart is fiction; lowlights
present but whispered; a data room whose index describes a better company
than its contents; the one embellished diligence answer that unwinds the
round.
