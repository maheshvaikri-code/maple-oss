# MAPLE demo package summary

This directory is a supplementary demonstration package for the MAPLE Python
runtime. It is intentionally outside the core release artifact.

The authoritative documentation is the [demo package README](README.md) and
the repository [root README](../README.md). The scripts demonstrate selected
messaging, resource, security, task, and autonomy flows locally. They are not
benchmark reports and do not establish production readiness, customer
deployments, compliance, or hosted service availability.

The package is not published by the Python release workflow. No registry
upload, cloud deployment, website publication, or release authorization is
implied by running a demo.

See the [2.0.0 release checklist](../docs/releases/v2.0.0.md) for the current
release boundary.
